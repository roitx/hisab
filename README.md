# 📱 Aasaan Hisaab Enterprise AI Pro Ledger

An ultra-modern, glassmorphic, dynamic, and multi-lingual AI-powered Khata & Expense Tracker web application. Designed to work seamlessly across all devices (Mobile, Tablet, Desktop) with automated AI transaction parsing, voice-to-text input, and real-time cloud data sync.

---

## ✨ Features

- 🎨 **Ultra-Premium UI/UX:** Built with a modern Glassmorphism theme, subtle neon glows, and 100% responsive touch-friendly UI.
- 🎙️ **Voice & AI Processing:** Integrated with Groq AI Engine (`llama-3.3-70b`) & Speech Recognition for natural language Hindi/English expense logging.
- 📊 **Visual Analytics:** Interactive Chart.js graphs (Bar Chart, Pie Chart, Line Graph) for income vs. expense insights.
- 📄 **Export & Reports:**
  - One-click PDF Ledger Statement generation (jsPDF AutoTable).
  - Excel / CSV data export.
  - Direct WhatsApp summary and debt-reminder sharing.
- ☁️ **Cloud Sync & Offline Support:** Powered by Firebase Firestore with offline local storage capabilities.
- 🔐 **Security & Wallets:** Protected with 4-digit security PIN login and multi-wallet filtering (Cash, Bank, Credit, Udhar).
- 💾 **Data Backup & Restore:** Offline JSON file backup and restore utility.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Grid/Flexbox, Custom Variables, Glassmorphism), JavaScript (ES6+)
- **AI Processing:** Groq API (`llama-3.3-70b-versatile`)
- **Cloud Database:** Firebase Firestore Engine
- **Data Visualization:** Chart.js
- **Document Generation:** jsPDF & jsPDF-AutoTable
